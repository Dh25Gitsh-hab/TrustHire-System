# TrustHire

A web platform that checks **the company behind a job posting** — domain age,
online reputation, reviews, MCA registration and hiring-process red flags — and
returns an explainable trust score.

Final-year B.Tech (CSE) project, JSS Academy of Technical Education, Noida.

| `backend/`  | Python 3.10+ / FastAPI API — see `backend/README.md`           |
| `frontend/` | React (Vite) + Tailwind CSS web app — see `frontend/README.md` |
